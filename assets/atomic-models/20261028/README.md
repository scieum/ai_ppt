# 원자모형 변천 — 생성 이미지 에셋

2026-10-28 · NotionTalk 웨비나 · 현재 21장 PPT의 17쪽

사용자 요청에 따라 간단한 벡터 도식을 투명 배경의 주황색 3D 삽화로 교체했다. `thomson.png`, `rutherford.png`, `bohr.png`는 내장 `image_gen.imagegen`으로 각각 새로 생성한 원본 PNG다. 생성 후 픽셀이나 알파를 편집하지 않았으며 PPT에는 가로세로 비율을 유지해 넣었다. 상세 생성 프롬프트와 원본 저장 경로는 [provenance.json](provenance.json)에 있다.

| 파일 | 설명할 차이 |
|---|---|
| thomson.png | 퍼진 양전하를 나타내는 주황색 구 내부에 전자가 들어 있다. 중심 원자핵을 그리지 않았다. |
| rutherford.png | 작은 중심 핵과 주변 공간, 설명용 경로를 표시했다. |
| bohr.png | 허용 궤도의 반지름이 구분되도록 두 동심 궤도를 표시했다. |

이미지는 실제 원자의 사진이나 정확한 크기 비율이 아닌 개념 모식도다. 전자 수로 특정 원소를 나타내지 않는다. 러더퍼드의 선은 관측한 실제 전자 궤적이 아니라 설명용 표시다. 보어 모형의 허용 궤도는 현대의 오비탈과 구분한다. 당시 모형에 현대적인 양성자·중성자 덩어리를 덧붙이지 않았다. 장표 아래에도 전자 수·크기 비율을 단순화했다는 문구를 표시한다.
