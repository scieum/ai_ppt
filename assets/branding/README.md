# 강의 브랜드 원본 자산

매 새 강의를 시작할 때 사용자가 사이음/노션톡을 지정하지 않았다면 **“이번에는 사이음/노션톡 중 무엇인가요?”**라고 질문한다. 이전 강의의 브랜드를 새 강의에 자동으로 적용하지 않는다. 같은 강의에서 이미 선택했다면 재질문하지 않는다.

| 선택 | 우측 상단 로고 | 푸터 권리자 |
|---|---|---|
| 사이음 | 원본 하네스의 사이음 로고 | `Sci_eum` |
| 노션톡 | 제공된 노션톡 흰색/검정색 로고 | `NotionTalk` |

어두운 바탕에는 흰색, 밝은 바탕에는 검정색 로고를 사용한다. 원본의 형태·질감·비율·투명도를 유지한다. 두 PNG는 2026-10-27 사용자가 제공한 파일을 바이트 변경 없이 보관한 것이다. 해시와 원본 파일명은 `catalog.json`에 있다.

- `notiontalk-black.png`: `3ac105fd-6aa1-4bb0-aa3a-ab88645874a4.png`
- `notiontalk-white.png`: `51d4ba92-b469-436b-8ca7-441e5b8919a3.png`

사이음 원본 `logo(black).png`는 현재 체크아웃에 포함되어 있지 않다. 실제 사이음 강의 제작 시 원본 위치를 확인하고 자산 기록을 보완한다. 임의 재제작이나 텍스트 대체로 로고 준비 완료를 처리하지 않는다.

푸터는 기존 문구의 권리자 부분만 바꾼다. 연도·기호·접두·접미 문구는 유지한다. 예를 들어 `© 2026. Sci_eum. All rights reserved.`는 노션톡 선택 시 `© 2026. NotionTalk. All rights reserved.`가 된다. `@`를 포함하는 기존 형식이면 `@{holder}`처럼 기호를 템플릿에 유지한다.
