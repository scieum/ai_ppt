# 논리 관계에 맞춰 쓰는 장표 에셋

기준: 사용자 제공 2026-10-30 스크린샷 8개, 「기획부터 디자인까지 쭉! AI 디자인 하네스 만들기」. 7·8번은 같은 29쪽 캡처다. 문구·캐릭터·브랜드를 복제하는 대신 비교, 분기, 단계, 확인 지점의 정보 구조를 사용한다. 기존 노션톡 검정·주황·Pretendard, 원본 캐릭터와 로고를 유지한다.

| 표현 | 참고 | 적용 장표 | 사용하는 이유 |

`components.mjs`는 편집 가능한 네이티브 장표 요소를 만든다. 전체 슬라이드를 붙이는 방식이 아니다. `output/reference-logic-build/author.mjs`에 실제 적용 조합이 있다. 원본의 흰 비교 셀은 사용하지 않으며 기존 어두운 표 기준을 따른다. 대비를 위한 보조 파랑은 버전 대조의 오른쪽에만 사용한다.

## 적용 범위

43장 순서를 유지한다. 3쪽 준비물 박스·간격, 표지, 목차, 파트 전환, 모션 예제, 캘린더와 사이클 활동은 변경하지 않는다. 이미 구조가 적합한 25·33·34쪽 표도 그대로 둔다. 기존 캐릭터는 원래 있던 20·37·40쪽에서 배치만 조정하며 새 캐릭터 컷을 추가하지 않는다.

## 출처 및 검토 경계

스크린샷 원본은 내부 참고용으로 `references/`에 보관한다. 원본의 문구, HuddlingClub 로고, 펭귄, 예제 주제는 결과 장표에 삽입하지 않는다. 새 문구는 노션톡 웨비나의 기존 설명을 재구성한 것이다. 이 기록은 법적 저작권 승인이나 기존 G10 검토의 완료를 의미하지 않는다. 기존 G10 상태는 변경하지 않는다.

## 확정 결론 바 스타일 — v32

사용자가 결론 바를 별도로 지정했다. `conclusion-bar.mjs`를 우선 사용한다. 왼쪽 라벨은 흰 글씨 ‘결론’과 주황 배경, 본문은 거의 검정인 주황 계열 배경과 흰 글씨, 외곽은 얇은 주황 테두리다. 라벨 오른편을 직선으로 이어 별도 캡슐처럼 보이지 않게 한다. 본문 문구를 바꾸지 않고 핵심 요약에만 사용한다. 6쪽은 캐릭터와 겹치지 않게 카드 아래 폭에 맞춘다. 사용자 지정 캡처는 `references/conclusion-bar-request.png`에 내부 참고용으로 보관한다.
