# 원본 PDF 구조를 사용하는 장표 에셋

2026-10-27 사용자의 “원본 레퍼런스처럼 구조는 똑같이” 요청을 적용했다. 색·글자만 참고해 새로운 레이아웃을 만드는 방식은 이 작업의 기준이 아니다.

각 폴더의 `source.png`는 원본 한 쪽의 렌더다. `background.png`/`background.svg`는 교체할 글자·그림·기존 로고를 제거하고 남은 실제 원본 도형과 배경이다. 기본 chevron이나 새 카드로 재제작하지 않았다. `catalog.json`에 원본 파일명·쪽수·SHA-256을, `layouts.json`에 텍스트 슬롯과 구성 요소의 실측 좌표를 기록했다. 캔버스는 원본 그대로 1920×1080이다.

## 사용

1. 강의별 페이지를 이 중 한 유형에 연결한다. 다른 구조가 필요하면 해당 원본 쪽을 추가 추출한다.
2. 배경을 전체 캔버스에 놓고 `layouts.json`의 슬롯에 새 문구를 넣는다. 도형 수·폭·순서·간격을 임의로 바꾸지 않는다. 긴 문구는 먼저 줄인다.
3. 새 강의 브랜드 미지정 시 사용자에게 사이음/노션톡을 질문한다. 선택한 원본 로고만 우측 상단에 넣고 저작권의 권리자만 바꾼다. 라이브러리 배경에는 특정 브랜드를 구워 넣지 않는다.
4. 원본과 최종 PowerPoint 렌더를 같은 크기로 나란히 검토한다. 추출 배경을 넣었다는 사실만으로 글자나 이미지까지 일치한다고 판정하지 않는다.

PDF에 익명 Type3 글꼴과 윤곽선이 들어 있어 원본 폰트 패밀리는 신뢰성 있게 확인하지 못했다. 새 글자는 설치된 Pretendard를 사용하며 원본 실측 크기를 따른다. 글꼴 완전 동일성을 주장하지 않는다.

배경과 도형은 고정 에셋이다. PPTX의 새 문구는 편집 가능하지만 도형까지 모두 네이티브 편집 가능한 원본 PPTX를 복원한 것은 아니다. SVG도 보관해 확대·추가 추출에 사용할 수 있다. 출처와 로컬 참조 용도를 유지하며 독립 자산으로 외부 배포하는 라이브러리로 간주하지 않는다.

재추출은 원본 PDF와 `output/reference-analysis/inventory.json`을 준비한 뒤 `build_assets.py --deps <PyMuPDF 설치 경로>`로 실행한다. 원본 PDF는 수정하지 않는다. 이미 추출한 에셋을 사용하는 데는 Python 의존성이 필요 없다.
