# 레퍼런스형 도구 로고

클로드·코덱스·힉스필드 로고를 레퍼런스의 **어두운 유리 질감, 둥근 앱 배지, 얇은 테두리, 은은한 반사** 형식으로 정리했다. 로고 윤곽을 AI로 새로 그리지 않고 제공된 PDF의 벡터 패스를 직접 추출했다. 브랜드 표식의 비율을 유지하고 배지 틀만 공통 SVG로 구성했다.

| 로고 | 표식 근거 | 색상 |
|---|---|---|
| Claude | R01 PDF 5쪽, Claude Code 항목 | 원본의 테라코타 계열 |
| Codex | R01 PDF 5쪽, Codex 항목에 쓰인 OpenAI 매듭 심볼 | 흰색 |
| Higgsfield | R06 PDF 7쪽, 힉스필드 소개 아이콘 | 원본의 라임 계열 |

R01은 `[4차 사이클 라이브] 기획부터 디자인까지 쭉! AI 디자인 하네스 만들기 (1).pdf`, R06은 `[허들링 클럽] 0802 AI 생성형 이미지 만들기 (1).pdf`다. 원본 파일 해시·쪽·벡터 경계·출력 해시는 `catalog.json`에 기록했다. 힉스필드 표식은 원본 장표에서 이미 기울어져 있어 이를 정면으로 정규화한 뒤 공통 각도 변형을 만들었다.

## 파일

- `png/*-front.png`: 정면 배지, 1024×1024 투명 PNG. PPT에 바로 삽입한다.
- `png/*-tilted.png`: -18° 기울임 배지, 같은 투명 캔버스. 소개 장표에 사용한다.
- `svg/`: 위 배지의 확대 가능한 벡터 원본. 모든 로고 패스가 포함되어 외부 파일이나 폰트에 의존하지 않는다.
- `marks/`: 배지 없는 표식만의 투명 PNG·SVG.

투명 영역 덕분에 같은 파일을 검정·흰 배경 모두에 사용할 수 있다. 장표에서 삽입할 때 가로세로 비율을 고정하고, 같은 유형은 같은 크기의 캔버스로 배치한다. 원본 브랜드 색을 웨비나의 주황색으로 일괄 바꾸지 않는다.

코덱스는 **레퍼런스에서 사용한 OpenAI 심볼형**이다. 별도의 최신 Codex 앱 아이콘 원본을 다운로드했다고 표시하지 않는다. 이 묶음은 공식 브랜드 배포 패키지가 아닌 제공 레퍼런스를 바탕으로 만든 강의용 재구성 에셋이다.

도구 설명용 로고이며 우측 상단의 노션톡 브랜드 로고와 교체하지 않는다. 실제 사용 장표가 정해지면 해당 강의 자산 매니페스트에 파일과 용도를 등록한다.
