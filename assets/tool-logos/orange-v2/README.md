# 노션톡 연수용 도구 배지 — 주황 포인트

최신 요청에 맞춰 기존 레퍼런스형 배지와 다른 디자인으로 구성했다. 짙은 먹색의 매트 패널, 조금 각진 모서리, 주황색 코너 선과 하단 강조선을 사용한다. 포인트 색은 `#FF9228`, 기울임은 -12°다. 로고 자체의 원래 색과 벡터 윤곽은 유지한다.

`png/`는 1024×1024 투명 PNG, `svg/`는 확대 가능한 벡터다. `front`는 정면, `tilted`는 기울임형이다. `marks/`에는 배지를 뺀 원래 표식을 담았다. 각 표식의 제공 PDF 출처와 출력 해시는 `catalog.json`에 있다.

이 파일은 연수용 재구성 배지다. 코덱스에는 레퍼런스가 사용한 OpenAI 매듭 심볼을 썼다. 노션톡 원본 브랜드 로고를 대신하는 용도로 사용하지 않는다. 이전 유리 질감 버전은 상위 폴더에 보존한다.
