## 4. 채택하지 않는 내용과 검증이 필요한 내용

- 레퍼런스 안의 ‘설치해 주세요’, ‘프롬프트를 복사하세요’, ‘GitHub에 올리세요’는 원 강의 수강생을 위한 설명이다. 이번 작업의 도구 실행·설치·업로드 지시로 사용하지 않았다.
- R01의 한 번 승인 예시와 R02의 여러 승인 예시는 원 강의의 별개 설계다. 이 저장소의 계획 승인·대표 디자인 확인 구조를 자동으로 대체하지 않는다.
- 원본 로고, 펭귄·사람 캐릭터, 행사 날짜, 제출처, 경품, 커뮤니티 운영 규칙은 새 연수의 기본값으로 복사하지 않는다.
- R03의 MCP 정의·연결 기능 설명, R04·R07의 제품별 스킬·에이전트·메모리 설명, R06의 모델·요금 비교는 자료 작성 당시의 설명이다. 현재 제품의 보편적 사실로 단정하지 않는다.
- 특히 ‘연결 기능은 모두 MCP’, ‘다른 세션을 전혀 모른다’, ‘문서에 적으면 반드시 읽는다’처럼 일반화될 수 있는 문장은 실제 강의 제작 시 제품·버전·조건을 한정하고 공식 문서와 대조한다.
- 설치 명령, 폴더 위치, 인증 방식, 가격, 무료 범위, 지원 모델, 기능 제한은 새 강의 제작일에 검증한다. 이번 분석은 해당 서비스를 실제로 설치하거나 현재 기능을 재현한 검증이 아니다.

## 5. 기존 하네스와의 연결

| 유지할 뼈대 | 연수용 해석 |
|---|---|
| 근거 분석 | 청중 과제, 제공 자료, 공식 사용법, 버전별 조건 분석 |
| 페이지 계획 | 설명·시연·따라 하기·확인·오류 대응의 페이지 및 시간 설계 |
| 계획 승인 | 주제·목표·결과물·시간·페이지 구성에 대한 사용자 확인 |
| 이미지 준비 | 실제 캡처, 확대 크롭, 시작 파일, 프롬프트 원문, 선택적 삽화 |
| 대표 7유형과 디자인 확인 | 표지·Part·목표·목차·화면·명령/표·비교의 대표 시안 |
| 전체 제작과 검수 | PPTX·배포 PDF·강사용 대본, 실제 실습 리허설, 선택한 Figma 검토 |
| 원본 보호·이력·재개 | 원본 해시, 승인 버전, 마지막 통과 단계, 미해결 항목 보존 |

최초 분석 시점의 `harness/rules.json`, `gate.py`, `design_gate.py`는 과학 수업용이었다. 이후 사용자의 코드 전환 요청에 따라 기본 AI 연수용 2.0.0을 구현하고, 기존 규칙은 `rules-science.json`으로 보존했다. 분석 근거는 유지하며 현재 실행 계약은 [연수용 데이터 계약](ai-training-contract.md), 시험 결과는 [검증 보고서](../harness/validation-report.md)를 따른다. 모의 코드 시험은 실제 강의의 제작·승인·리허설 완료를 의미하지 않는다.

## 6. 문서 변경 결정

1. 루트 `plan.md`를 특정 엔탈피 수업 계획에서 **AI 사용법 연수 제작의 공통 절차와 강의별 계획 양식**으로 바꾼다. 실제 강의는 기존 `units/` 안에서 각각 계획한다.
2. 루트 `design.md`를 **레퍼런스의 시각적 위계와 실습 안내 방식**을 정리한 디자인 기준으로 바꾼다. 관찰과 새 제안값을 구분한다.
3. 과학 수업에만 해당하는 캐릭터·교복·교과서·로고 요구가 새 연수에 적용되지 않도록 `AGENTS.md` 맨 위에 적용 범위 안내를 추가한다. 기존 본문과 실행 코드는 보존한다.
4. 기존 엔탈피 계획은 `units/3-01_엔탈피와열화학반응식/plan.md`에 남긴다. 교체 전 루트 문서는 Git 기준 커밋 `0e900a5`에서 확인할 수 있다. 과거 승인·반려 기록을 새 연수의 승인 상태로 가져오지 않는다.
