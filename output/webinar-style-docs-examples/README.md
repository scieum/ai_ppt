# 노션톡 기준 문서 예시

2026-10-29. 웨비나 24~31쪽과 34~39쪽을 설명하기 위한 Markdown 예시다. 파일 내용은 교육용 자체 제안이며 실제 사용자 승인이나 영상 제작 완료 기록이 아니다.

- storyline.md: 이번 영상의 내용·문구·장면·구간.
- design.md: 반복해 사용할 시각 스타일과 자산 기준.
- motion.md: 반복해 사용할 등장·속도·간격·전환 기준.

세 파일은 일반 Markdown 자료다. 다음 작업에서 함께 제공하고 어떤 파일을 참고할지 분명하게 정한다. 도구가 파일 이름만 보고 자동으로 읽는다는 뜻은 아니다. 같은 톤을 이어가는 데 쓰는 기준이며 결과의 완전한 일치를 보장하지 않는다.

별도 프로젝트에서는 design.md에 적힌 실제 로고·캐릭터 파일과 대표 스틸컷·기준 영상도 함께 전달한다. 이 ZIP에는 문서 네 개만 들어 있으며 영상·스틸컷·브랜드 PNG는 포함하지 않았다. 저장소의 실제 자산 위치는 design.md에 적혀 있다.

문서 역할을 확인한 뒤 내용을 고쳐 사용한다. 장면 하나의 예외와 앞으로 사용할 공통 기준의 변경을 구분하고 문서·자산·결과물 버전을 맞춘다. 이 예시의 지시는 현재 하네스를 변경하거나 외부 도구를 실행하는 명령이 아니다.
