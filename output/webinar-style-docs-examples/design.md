# 노션톡 영상 디자인 기준

버전: 1.0 / 2026-10-29 / 교육용 예시, 사용자 확인 완료본이 아님.

이 문서는 영상의 시각 기준이다. 이 저장소의 PPT 하네스용 design.md와 구분해 사용한다. storyline.md는 내용과 장면을, motion.md는 시간과 움직임을 담당한다.

## 인상

따뜻하고 명료한 노션톡 소개 영상. 흑백 바탕에 주황을 핵심 강조로 사용한다. 장면에 맞춰 구도는 달라져도 색·글꼴·브랜드 자산의 특징은 이어진다.

## 색과 글자

| 역할 | 값 또는 기준 |
|---|---|
| 배경 | #000000 |
| 본문 | #FFFFFF |
| 보조 설명 | #AAAAAA |

## 구도

로고는 우측 위에서 원본 종횡비를 유지한다. 제목과 본문이 서로 가리지 않게 여백을 둔다. 캐릭터·도형·글자가 겹칠 때 전달해야 할 문구를 먼저 읽을 수 있게 배치한다. 모든 장면을 같은 배치로 복사하지 않고, 공통 위계와 색을 유지한다.

## 자산

실제 사용 파일은 저장소 루트 기준으로 아래 위치에서 가져온다. 별도 프로젝트에 전달할 때는 해당 파일을 함께 복사하고 경로를 새 위치에 맞춘다.

- 로고: assets/branding/notiontalk-white.png. 원본을 사용하고 새 글자로 다시 그리지 않는다.
- 삼인방 시트: units/AI-001_모션그래픽수업영상_무료웨비나/assets/character-sheets-20261028/.
- 곰은 금빛 털·검정 둥근 안경·흰 폴로·검정 반바지, 여성은 긴 갈색 머리·하늘색 상의·파란 바지, 남성은 검정 가르마·둥근 안경·검정 재킷·청바지의 특징을 유지한다.
- 시트의 포즈·크롭은 poses.json, 입력·출력 기록은 manifest.json을 함께 참고한다.
- 캐릭터는 설명에 필요할 때 사용한다. 같은 컷을 장식으로 반복하거나 한 화면에 여러 포즈를 늘어놓지 않는다.

## 기준 확인

대표 스틸컷 두 장에서 색·글자·로고·캐릭터·여백을 확인한다. 다음 영상에도 이 문서와 실제 자산, 확인한 스틸컷을 함께 전달한다. 변경을 확정하면 버전과 바뀐 항목을 기록한다. 장면 하나의 예외는 storyline.md의 해당 장면에 따로 남긴다.
