# 노션톡 영상 모션 기준

버전: 1.0 / 2026-10-29 / 교육용 예시, 사용자 확인 완료본이 아님.

이 문서는 일반 Markdown 작업 자료다. 도구가 이름만 보고 자동 적용한다고 가정하지 않고 작업할 때 함께 제공한다. 아래 수치는 같은 톤을 비교하기 위한 출발점이며, 보편적인 정답은 아니다.

## 전체 시간

- 15초, 30fps, 16:9의 소개 영상 예시다.
- 장면은 0~4초 / 4~10초 / 10~15초로 구분한다.
- 전환은 이 구간 안에서 배치하고, 전환 때문에 전체 길이가 15초를 넘지 않게 확인한다.
- 초 단위 기준은 실제 재생과 읽는 시간을 보며 조정한다.

## 공통 움직임

| 항목 | 출발 기준 |
|---|---|
| 등장 | 0.45초 동안 페이드와 위쪽 이동을 함께 사용 |
| 시작 위치 | 최종 위치보다 아래쪽 16px |
| 가감속 | 처음에는 빠르게, 끝으로 갈수록 천천히 |
| 순차 등장 | 다음 요소의 시작은 앞 요소보다 0.12초 늦게 |
| 퇴장 | 0.25초 페이드 |
| 장면 전환 | 0.3초 동안 이전 장면과 겹쳐 전환 |
| 마지막 문구 | 1.2초 이상 정지해 읽을 시간 확보 |

시작 간격과 각 요소의 지속시간은 서로 다른 값이다. 세 요소가 0.12초 간격으로 시작하더라도 각각의 등장 지속시간은 0.45초일 수 있다.

## 장면과 자산

시각 요소는 design.md의 색·글꼴·자산을 사용한다. 움직임을 수정하면서 얼굴·의상·로고를 임의로 바꾸지 않는다. 한 장면의 특별한 유지시간은 storyline.md의 장면별 예외에 기록한다. 공통 등장 속도를 바꾸기로 확인했다면 이 문서의 기본값과 버전을 함께 바꾼다.

## 소리

내레이션이 있으면 핵심 단어가 말해지는 시점과 강조의 시작을 함께 본다. 소리가 없는 예시는 무음 예시로 표시한다. 음악·효과음을 추가한다면 사용할 음원과 동기화 시점을 별도로 확인한다.

## 검토

스틸컷으로 확인할 수 있는 것은 정지 모습이다. 예를 들어 4~7초의 짧은 구간을 재생해 등장 순서·간격·속도를 보고, 마지막으로 15초 전체를 확인한다. 바뀐 구간뿐 아니라 앞뒤 장면의 연결과 문구를 읽을 시간도 살핀다.
