## 목표

참가자는 모션 그래픽이 어떤 표현인지 이해하고, 화면에서 보이는 변화를 쉬운 말이나 효과 이름으로 설명한다. 문장·웹사이트·과학사 중 자기 수업에 맞는 출발점을 골라 짧게 요청하고, 결과에서 발견한 문제를 구체적인 수정 조건으로 바꾼다.

세 예제는 같은 기준의 세 장르가 아니다. 타이포그래피는 표현 형식, 웹사이트 URL은 입력 방법, 원자모형 변천은 설명 주제다. 한 영상에서 여러 표현 유형을 함께 사용할 수 있다.

## 개념 설명에서 구분할 것

- 모션 그래픽은 그래픽 디자인 요소를 움직여 정보를 전달하는 표현이다. 애니메이션은 더 넓은 범주다.
- Position·Scale·Rotation·Opacity는 속성이다. Fade·Slide·Zoom·Wipe·Typewriter는 보이는 변화의 이름이다. 앱마다 효과 이름과 구현 방식이 다를 수 있다.
- Stagger는 여러 요소의 시작 간격을 두는 규칙, Easing은 움직이는 동안 속도가 달라지는 방식이다. 한 효과 메뉴의 존재를 보편적으로 단정하지 않는다.
- 불투명도와 흐림을 구분한다. 투명하게 시작해 보이게 하는 것과 초점을 선명하게 만드는 것은 다르다.
- 키프레임은 특정 시점의 상태를 정하는 기준점이다. 모든 프레임을 직접 그려야 한다는 뜻은 아니다.
- 시작 전 대기·움직임·읽기 유지를 분리한다. 수치는 강의용 예시이며 모든 문장에 같은 유지 시간을 적용하지 않는다.
- 10쪽 아래 도형 시연은 1.8초의 동일 지속 시간으로 속도를 비교한다. 위의 0.8초 요청 예시와 동일한 실행 결과라고 말하지 않는다.

공식 근거는 [기초 설명 근거](research/motion-foundations-20261028.md)를 따른다. 2026-10-28에 Autodesk의 정의와 Adobe의 이징 설명을 다시 확인했다.

## A. 노션톡 무료 웨비나 홍보 타이포그래피

20초 자체 구성: 0~4초 주제 소개, 4~16초 핵심어 전개, 16~20초 일정과 참여 안내. 문구가 길면 문구나 길이를 다시 조정한다.

```text
‘수업 자료가 영상이 되는 순간’으로 시작하는
노션톡 무료 웨비나 홍보 타이포그래피를 20초로 만들어 줘.
글자가 차례로 이어지고 핵심어가 강조되게 해 줘.
검정 바탕에 주황색 포인트를 써 줘.
마지막에는 ‘2026년 11월 1일 일요일 저녁 8시’와
‘댓글에 노션톡을 남겨 주세요’를 넣어 줘.
지금 환경에서 재생할 수 있는 결과로 보여 줘.
```

첫 결과에서는 필수 문구와 일정, 한글 표시, 처음부터 끝까지 재생되는지 본다. 마지막 안내가 빠르면 다음 조건을 추가한다.

```text
전체 길이는 20초로 유지하고,
마지막 안내를 4초 동안 읽을 수 있게 앞 장면의 시간을 조정해 줘.
```

로고는 사용자 제공 원본을 사용하고 생성 모델로 다시 그리지 않는다. HTML 미리보기와 MP4 출력은 별도로 구분한다.

## B. 공식 웹사이트 내용을 이용한 소개 영상

실습 URL은 제작자가 선정한 [Notion 공식 문서 소개](https://www.notion.com/ko/product/docs)다. 사용자가 지정한 사이트라고 기록하지 않는다. 블록으로 내용 구성하기·목차로 찾아가기·함께 편집하기의 정보를 출발점으로 삼고, 각각 쓰임을 설명하는 장면을 만든다.

```text
다음 공식 페이지를 읽고 Notion 문서를 소개하는
30초 모션 그래픽 초안을 만들어 줘.
https://www.notion.com/ko/product/docs
블록으로 내용 구성하기, 목차로 찾아가기,
함께 편집하기를 각각 한 장면으로 설명해 줘.
원문과 영상 문구를 짝지어 보여 줘.
페이지를 읽지 못하면 먼저 알려 줘.
```

2026-10-28 확인: 제품 페이지 직접 열기는 시간 초과였고, 공식 제품 페이지 검색 수집 내용과 [목차 도움말](https://www.notion.com/help/columns-headings-and-dividers), [협업 도움말](https://www.notion.com/ko/help/collaborate-within-a-workspace)을 대조했다. 성공적으로 현재 페이지 본문 전체를 연 것으로 처리하지 않는다. 실습에서는 실제 접근 여부를 확인하고, 열지 못하면 강사가 확인한 텍스트를 제공한다.

영상 문구와 원문이 대응해야 한다. 원문에 없는 주장은 제거한다. 내용 근거로 읽는 것과 화면 디자인의 참고는 구분한다. 사이트 화면은 실제 캡처, 개념 설명은 개념 장면으로 표시하며 생성 UI를 실제 UI처럼 사용하지 않는다.

## C. 원자모형 변천 지식 전달

```text
톰슨·러더퍼드·보어의 원자모형 변천을 설명하는
45초 모션 그래픽 초안을 만들어 줘.
각 모형의 특징, 이전 설명의 한계, 바뀐 이유를
짧은 문장과 개념 모식도로 보여 줘.
핵심 주장에 사용한 근거를 연결하고,
새로 확인해야 할 사실은 따로 표시해 줘.
보어 모형을 현대 원자모형의 최종 형태로 설명하지 마.
```

생성한 세 이미지는 [원자모형 에셋](../../assets/atomic-models/20261028/README.md)의 원본 PNG를 유지했다. 톰슨은 퍼진 양전하와 내부 전자, 러더퍼드는 작은 중심 핵, 보어는 구분된 허용 궤도를 강조한다. 실제 사진이나 정확한 비율이 아니며 전자 수로 특정 원소를 나타내지 않는다. 러더퍼드 경로선은 관측한 전자 궤적이 아니다.

사실 기록은 [AIP 톰슨](https://history.aip.org/exhibits/electron/jjelectr.htm), [AIP 러더퍼드](https://history.aip.org/exhibits/rutherford/sections/alpha-particles-atom.html), [보어 Nobel 강연](https://www.nobelprize.org/uploads/2018/06/bohr-lecture.pdf) 및 기존 과학사 자료를 대조한다. 관찰과 모형의 해석을 구분하고 보어 모형 이후의 설명이 있음을 짚는다.
