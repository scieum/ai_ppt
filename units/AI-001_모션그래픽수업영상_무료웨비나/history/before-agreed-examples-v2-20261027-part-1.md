# Part 1 — 모션 그래픽의 종류와 세 가지 제작 사례

2026-10-27 · 최신 구성 제안. 기존 질문 영상·버튼 조작 중심 초안을 대체한다. 노션톡·주황 포인트·G10 기준과 전체 다섯 단계는 유지한다.

먼저 [Part 0 오늘의 준비물](part-0.md)에서 선택한 Codex 또는 Claude의 유료 요금제 구독과 로그인을 확인한다. 이번 강의의 필수 준비 조건이며, 구독 완료 후의 기술 오류·생성 지연에만 관찰·백업 합류를 제공한다.

## 도입: 어떤 영상을 만들 수 있나요?

먼저 결과 영상을 짧게 보여 주고 유형과 활용 상황을 설명한다. 타이포그래피, 인포그래픽, 웹사이트·서비스 소개, 역사·타임라인 설명, 절차 안내, 캐릭터 설명 등을 소개하되 용어 설명을 길게 늘이지 않는다. 이번 웨비나는 아래 세 제작 사례를 중심으로 진행한다.

| 사례 | 시작 입력 | 보여 줄 영상 | 핵심 경험 |
|---|---|---|---|
| A. 텍스트 타이포그래피 | 짧은 문장 여러 개 | 문장이 차례로 이어지고 핵심어가 커지는 영상 | 텍스트만으로 움직이는 화면 만들기 |
| B. 웹사이트 링크 기반 | 실제 웹페이지 URL | 페이지의 내용을 재구성한 소개·홍보·요약 영상 | 원자료를 읽고 핵심 메시지와 장면으로 바꾸기 |
| C. 역사 지식 전달 | 역사 주제와 확인할 자료 | 사건의 배경·변화·의미를 설명하는 영상 | 지식을 이야기·연표·설명 장면으로 풀기 |

타이포그래피는 표현 형식, URL은 자료 입력 방식, 역사는 설명할 주제다. 세 가지를 강의의 제작 사례로 묶고, 앞에서는 더 넓은 영상 유형을 먼저 보여 준다.

## A. 문장이 이어지는 타이포그래피

15~20초 제안. 기존의 세 질문 화면 전환보다 여러 문장의 리듬·강조·크기 변화가 보이게 한다. 예제 문구는 새로 작성한다.

> 다음 문장들이 차례로 이어지는 20초 타이포그래피 영상을 만들어 줘. ‘오늘 배울 것’, ‘핵심을 찾고’, ‘순서를 따라’, ‘연결해 봅니다’, ‘이제 시작합니다’. 중요한 단어는 크게 보여 주고, 검정 바탕에 주황색 포인트를 넣어 재생 가능한 미리보기로 보여 줘.

관찰: 문장이 이어지는 흐름, 핵심어의 강조, 읽을 수 있는 시간. 수정은 문구 하나 또는 강조 하나부터 한다. 단순 슬라이드 전환과 글자 자체의 움직임을 비교한다.

## B. 웹사이트 내용을 영상으로 바꾸기

30~45초 제안. 실제 사용할 URL은 아직 정하지 않았다. 서비스 소개 페이지·강의 안내 페이지·온라인 전시 설명 페이지 등이 후보이며 확정한 것으로 쓰지 않는다.

> [실제 사용할 URL]의 내용을 읽고 이 사이트를 소개하는 30초 모션 그래픽 영상 초안을 만들어 줘. 누구를 위한 사이트인지, 핵심 내용 세 가지, 이용 방법 순서로 보여 줘. 검정 바탕에 주황색 포인트를 넣고 재생 가능한 미리보기로 보여 줘. 페이지를 읽지 못하면 먼저 알려 줘.

화면 전개: 실제 원문 페이지 → AI가 추린 핵심 내용 → 재구성한 영상. 웹페이지의 내용을 원자료로 사용하는 것이며, 사이트 UI를 스크롤하는 화면 녹화와 구분해 설명한다. 시각 스타일 레퍼런스를 첨부하는 작업은 Part 2에서 다룬다.

확인: 페이지를 실제로 읽었는지, 소개·기능·이용 방법이 원문과 맞는지, 날짜·행사·가격 등 변동 정보가 맞는지. 접근 불가 시 사용자가 제공한 본문으로 전환하고 URL을 읽었다고 표시하지 않는다. 공개된 페이지라도 로고·사진·문장의 재사용 조건은 별도로 G10에서 검토한다.

## C. 역사 지식 전달 영상

45~60초 제안. 예시 후보는 ‘훈민정음의 창제와 반포’이며 주제는 미확정이다. 여기서는 연도·역사적 주장·실제 출처를 확정하지 않는다. 제작 전 공신력 있는 자료에서 사실과 소재의 이용 조건을 확인한다.

> ‘훈민정음의 창제와 반포’를 설명하는 45초 지식 전달 모션 그래픽 영상 초안을 만들어 줘. 배경, 주요 사건, 의미 순서로 보여 주고 연도와 주요 사실에는 확인할 출처를 함께 적어 줘. 검정 바탕에 주황색 포인트를 넣고 재생 가능한 미리보기로 보여 줘.

화면 전개: 주제 질문 → 배경 → 사건과 변화 → 의미 정리. 연표·핵심어·지도·간단한 도형 등을 내용에 맞게 선택한다. 역사 관련 사실을 나열하는 데 그치지 않고 앞뒤의 관계를 시각적으로 설명한다.

AI가 적은 출처는 실제로 열어 해당 주장을 뒷받침하는지 확인한다. 인물·연도·사건 순서와 사실/해석을 구분하고, 미확인 주장은 배포본에서 제외한다. 생성한 시대 장면은 재현·설명용 이미지로 표시하며 사료나 실제 기록 사진으로 취급하지 않는다.

합계 18분 제안. 장 번호는 현재 전체 구성용이며 실제 제작에서는 사례별 조작 캡처 장표를 추가할 수 있다. 한 환경을 중심으로 세 강사 시연을 진행하고 다른 앱은 해당 사례의 실제 캡처로 비교한다. 참가자는 준비한 유료 계정에서 사례 하나를 골라 따라 한다. 기술 오류·생성 지연이 생기면 같은 조건의 강사 결과로 관찰 기록을 남긴다. 모든 참가자가 두 앱에서 세 편씩 완성한다고 약속하지 않는다. 시간은 리허설 전 추정값이다.

각 사례의 기본 전개는 완성 예시 → 시작 입력 → 실제 제작 화면 → 결과 재생 → 수정할 점이다. 코덱스와 클로드는 이 제작 과정을 보여 주는 환경으로 배치한다. 조작 화면 자체를 사례의 주제로 삼지 않는다.

## 실제 캡처와 기존 자료의 역할

각 사례에서 입력창·실제 프롬프트·요청 처리·결과 재생·수정 과정을 각각 캡처한다. URL 사례에는 실제 본문 확인·요약 대응, 역사 사례에는 사실·출처 확인 화면도 포함한다. 아직 하지 않은 실행이나 캡처를 완료로 표시하지 않는다.

| 자료 | 현재 상태 |
|---|---|
| 새 타이포그래피 사례 A | 계획만 작성, 새 영상·캡처 미제작 |
| 실제 웹사이트 URL과 사례 B | URL 미정, 본문 분석·영상·캡처 미제작 |
| 역사 주제와 사례 C | 주제 후보만 제안, 근거 확인·영상·캡처 미제작 |
| 기존 10초/11초 질문 영상과 캡처 15개 | 이전 조작 시연의 보조 자료로 보존 |
| 기존 두 앱 조작 PPT 12장 | 이전 보조 자료. 새 세 사례의 제작 완료본으로 사용하지 않음 |

## 뒤의 다섯 단계로 연결

Part 1에서는 짧은 요청으로 세 사례의 초안을 경험한다. Part 2에서는 웹사이트 소개 영상 등의 시각 레퍼런스로 표현 방향을 맞춘다. Part 3에서는 세 결과의 읽기 시간·등장 순서·강조를 모션 용어로 수정한다. Part 4에서는 역사 설명 사례를 LESSON_BRIEF.md·VISUAL_RULES.md·SCENE_PLAN.md로 정리해 일관된 결과를 만든다. Part 5에서는 필요한 장면 하나를 외부 커넥터로 확장한다.

웹사이트는 ‘내용의 원자료’, 시각 레퍼런스는 ‘보여 주는 방식의 참고’로 역할을 구분한다. 이번 개정은 계획 정리이며 새 영상·새 PPT·외부 생성 작업은 수행하지 않았다.
