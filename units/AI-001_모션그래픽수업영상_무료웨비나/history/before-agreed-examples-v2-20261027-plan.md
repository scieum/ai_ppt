# 모션 그래픽을 이용한 수업 영상 제작하기 — 웨비나 계획

개정: 2026-10-27 · 최신 구성 검토용 초안 · 브랜드: NotionTalk

## Part 0 오늘의 준비물

Part 1 전에 [Part 0](part-0.md)에서 준비물을 안내하고 실습 환경을 확인한다. AI 준비물은 **‘코덱스 or 클로드 유료 요금제’**로 간단히 표기한다. 컴퓨터·인터넷·로그인·예제 입력 자료·작업 폴더를 함께 준비한다. 유료 요금제 준비 조건은 유지하고 장표에 상세 요금·결제 설명을 늘이지 않는다.

## 1. 이번 강의의 중심

먼저 모션 그래픽으로 만들 수 있는 영상의 종류를 설명하고, 세 가지 제작 사례를 보여 준다. 기존의 짧은 질문 영상과 두 앱의 버튼 조작을 중심으로 했던 초안을 대체한다. 실제 조작 캡처는 사례의 제작 과정을 뒷받침하는 자료로 사용한다.

| 사례 | 입력 | 결과의 방향 | 상태 |
|---|---|---|---|
| A. 텍스트 타이포그래피 | 짧은 문장 여러 개 | 문장이 차례로 이어지고 핵심어가 강조되는 15~20초 영상 | 새 사례 계획만 작성 |
| B. 웹사이트 내용 기반 | 실제 웹페이지 URL | 본문을 재구성한 30~45초 소개·홍보·요약 영상 | URL 미정, 새 제작 미실행 |
| C. 역사 지식 전달 | 역사 주제와 확인할 자료 | 배경·사건·변화·의미를 연결하는 45~60초 설명 영상 | ‘훈민정음의 창제와 반포’ 후보, 미확정·미실행 |

영상 유형은 타이포그래피·인포그래픽·서비스 소개·타임라인·절차 안내·캐릭터 설명 등을 예시로 소개한다. 위 세 항목은 표현 형식·입력 자료·주제를 묶은 제작 사례이며 동일한 분류 기준의 세 장르라고 설명하지 않는다. 상세 진행과 요청 문구는 [part-1.md](part-1.md)를 따른다.

Part 1을 12분에서 18분으로 넓히고 Part 2·3·4·5를 각각 12·12·16·12분으로 조정했다. 시간은 사용자 확정이나 실제 리허설 결과가 아니다. 42장도 구성용 제안이며 필요한 조작별 캡처 장표를 추가한 뒤 실제 장수·시간을 다시 합산한다. 한 환경을 중심으로 시연하고 다른 앱은 해당 사례의 실제 캡처로 비교한다. 참가자는 유료 계정에서 사례 하나를 선택해 실습하며 기술 오류 시 관찰·백업으로 합류한다.

## 3. 자료와 확인 기준

- 웹사이트는 영상 내용의 원자료다. 본문을 실제로 읽었는지와 원문·요약·영상의 대응을 확인한다. 접근 불가 시 제공 본문을 사용하고 직접 열람과 구분한다. 실제 URL은 아직 정하지 않았다.
- 시각 레퍼런스는 색·배치·움직임 등 표현 방식의 참고다. 내용 자료와 역할을 구분하고 이용 근거가 있는 범위에서 사용한다.
- 역사 사례는 제작 전에 실제 출처에서 인물·연도·사건 순서·주장을 확인한다. AI의 출처 제시 자체를 확인 완료로 처리하지 않는다. 주제 후보와 영상 길이는 제안값이며 현재 역사적 사실이나 출처를 확정한 문서가 아니다.
- 재현용 생성 장면은 사료·실제 기록 사진과 구분한다. 문구·도형·이미지·음원·원문 인용과 배포 범위는 G10에서 검토한다.
- 생성이 늦어지면 같은 조건의 사전 결과로 관찰을 이어 간다. MP4 파일·HTML 미리보기·정지 이미지를 구분하고 실제 재생으로 확인한다.
