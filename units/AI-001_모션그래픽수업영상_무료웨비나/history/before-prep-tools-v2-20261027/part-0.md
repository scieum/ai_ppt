# Part 0 — 오늘의 준비물

2026-10-27 · 사용자 지정 준비 조건 반영. Part 1의 영상 유형·세 사례 소개 전에 진행한다. 표지 포함 현재 1~4장, 약 5분 제안이다.

## 장표에 넣을 문구

**코덱스 or 클로드 유료 요금제**

## 준비물

| 항목 | 참가자가 준비할 것 | 시작 전 확인 |
|---|---|---|
| 컴퓨터·인터넷 | 노트북 또는 데스크톱, 안정적인 인터넷 | 시연 화면과 작업 창을 함께 볼 수 있음 |
| 실습 AI | 코덱스 or 클로드 유료 요금제 | 사용할 계정으로 로그인 |
| 인앱 작업 환경 | 선택한 앱을 열어 실습 화면 준비 | 새 대화·작업을 열고 간단한 요청 전송 확인 |
| 예제 입력 자료 | 짧은 문장 여러 개, 영상으로 바꿔 볼 웹사이트 URL, 관심 있는 역사 주제 | 직접 고르거나 강사가 제공할 공통 예제 사용 |
| 저장 공간 | 프롬프트·영상·Markdown을 보관할 작업 폴더 | 파일을 저장할 위치 확인 |

공통 예제는 제공 예정으로 표시한다. 유료 요금제 준비 조건은 유지하며, 준비물 장표에는 위 문구로 간단히 표기한다.

## 장표별 진행

| 전체 장 | 제목 | 화면 핵심 | 제안 시간 |
|---:|---|---|---:|
| 1 | 웨비나 표지 | 강의명·일정·노션톡 브랜드 | 30초 |
| 2 | Part 0 오늘의 준비물 | 컴퓨터·인터넷·유료 AI 계정·입력 자료 | 1분 30초 |
| 3 | 코덱스 or 클로드 유료 요금제 | 사용할 도구를 선택하고 로그인 | 1분 |
| 4 | 로그인하고 실습을 시작해요 | 유료 구독 활성화·앱 로그인·새 대화·저장 위치 확인 | 2분 |

발화 제안: “준비물은 코덱스 or 클로드 유료 요금제입니다. 사용할 도구에 로그인해 주세요.”

## Part 1 연결

준비물 확인을 마친 뒤 [Part 1](part-1.md)의 영상 유형 소개, 텍스트 타이포그래피·웹사이트 내용 기반·역사 지식 전달의 세 사례로 이어 간다. 준비 단계에서 예제 제작 시연을 길게 시작하지 않는다. 노션톡 로고·주황 포인트와 기존 하네스 구조는 유지한다.
