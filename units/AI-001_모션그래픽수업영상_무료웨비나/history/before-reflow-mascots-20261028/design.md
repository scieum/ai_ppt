# 현재 장표 디자인 기준

최신 결과물은 output/webinar-knowledge-only/NotionTalk_모션그래픽_19장_영상핵심5장확장_v8.pptx와 PDF다. 총 19장이다.

기존 1~14쪽의 슬라이드 본문·이미지·노트·효과와 디자인을 변경하지 않는다. 주황·흑백·Pretendard·NotionTalk 원본 로고·푸터·표지 세 캐릭터를 유지한다.

15쪽은 기존 7쪽의 세 카드 구조, 16·18쪽은 기존 3쪽의 좌우 패널, 17·19쪽은 기존 13쪽의 편집 가능한 표 구조를 재사용한다. 원래의 제목 위치·여백·패널·표 크기·색을 유지하며 긴 문구를 좁은 곳에 억지로 넣지 않는다.

15쪽은 세 참고 방식의 차이를 자체 아이콘으로 설명한다. 16쪽은 이미지와 영상이 전달하는 정보를 나누고 기존 네이티브 등장 효과를 유지한다. 17쪽은 새 노션톡 스토리라인을 3장면으로 정리한다. 18쪽은 두 정지 장면을 편집 가능한 글자·도형으로 보여 준다. 19쪽은 수정 대상과 요청, 다시 확인할 결과를 연결한다.

18쪽은 원본 영상의 스틸컷이나 실제 AI 생성 결과를 캡처한 것이 아닌 강의용 자체 예시다. 원본의 화면·카피·스타일을 추출하지 않는다. 각 장표의 발표자 노트에 원본 구간과 자체 작성 부분을 기록한다. G10 상태를 임의로 승인 처리하지 않는다.
