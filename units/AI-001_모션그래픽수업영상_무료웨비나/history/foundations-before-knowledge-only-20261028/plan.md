## 최신 요청과 범위

사용자는 제작 실습만 제외하되 모션 그래픽의 뜻·종류·효과 이름 등 기본 개념은 앞부분에 유지하도록 명확히 정정했다. 이전 27장 구성에서 기초가 빠진 점과 전체 구성이 좋지 않다는 피드백을 반영한다. 기본 개념을 제거한 27장 구성은 현재 기준이 아니다.

현재 결과물은 [PPT](../../output/webinar-foundations-restored/NotionTalk_모션그래픽_기초복원_22장_v2.pptx)와 [PDF](../../output/webinar-foundations-restored/NotionTalk_모션그래픽_기초복원_22장_v2.pdf)다.

## 반드시 유지하는 기초

- 모션 그래픽의 뜻: 그래픽 요소를 시간에 따라 변화시켜 정보를 전달하는 표현
- 플립북: 조금씩 다른 상태가 이어지는 움직임의 비유와 기존 GIF
- 표현 종류: 키네틱 타이포그래피·인포그래픽·UI/서비스 소개·로고/타이틀·일러스트/캐릭터
- 기본 속성: 위치·크기·각도·불투명도
- 등장 효과: 페이드 인/아웃·슬라이드 인·줌/스케일
- 글자와 순서: 와이프/리빌·타이프라이터·순차 등장(Stagger)
- 시간과 속도: 움직이는 시간·읽는 유지 시간·이징·이즈 인/아웃

효과 이름과 바뀌는 속성, 표현 유형은 서로 구분한다. 예시를 보며 바로 이름과 의미를 연결한다. 슬라이드쇼의 개념 시연은 제작 실습에 해당하지 않으며 삭제하지 않는다. PDF는 정지 화면이다.

## 제외하는 제작 실습

프롬프트 입력·수정 요청 작성, 실제 앱 조작·생성·내보내기, Markdown 파일 및 장면표 작성, 외부 커넥터 실행, 파일 저장·제출 과제는 넣지 않는다. 실습 도구 준비물과 구독 안내도 현재 설명형 강의에는 배치하지 않는다. 자료를 직접 완성하는 참가자 과제나 실행 완료 증거를 요구하지 않는다.

## 사례의 역할

홍보 타이포그래피는 핵심어와 읽는 시간, 웹사이트 소개는 기능과 사용 상황, 수업 보조 영상은 변화의 순서와 차이를 보여 준다. 원자모형은 한 시계열 설명 예시로 유지한다. 앞에서 익힌 개념을 실제 쓰임과 연결하며 제작 방법을 따라 하는 장표로 바꾸지 않는다.

직전 27장의 추상적 목적·관점·차이 비교와 중복 사례 설명을 줄였다. 기존 대표 디자인 안에서 플립북·네이티브 효과·생성 모형 이미지와 구체적인 문구를 사용한다. 의미 없는 분량 확장과 비슷한 문장의 반복을 피한다.

## 근거

기초는 이전 21장 v5의 검증된 설명·공식 문서 출처를 복원한다. 사례·레퍼런스·음악·일관성은 루트 lesson.md의 여섯 영상 자막·설명란 분석을 참고한다. 이전 자료의 제작 실습 제안은 현재 사용자 요청과 구분한다. lesson.md 원문은 변경하지 않는다. 과학 모식도는 실제 원자 사진·관측 궤적·정확한 비율이 아니다.

20초와 마지막 안내 4초는 비교용 예시 값이고 9쪽 속도 시연은 두 도형 모두 1.8초다. 실제 생성 영상이나 리허설 결과로 표시하지 않는다. G10 재사용 자산의 권리 확인 상태와 기본 하네스 코드는 그대로 유지한다.
