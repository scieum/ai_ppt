## design.md를 설명하는 말

“깔끔하게”라는 느낌을 그대로 남기기보다, 다시 사용할 색상 값·글꼴·제목 위계·로고 위치·캐릭터 특징을 기록한다. 노션톡 예시는 배경 #000000, 본문 #FFFFFF, 강조 #FF9228, Pretendard, 우측 위 원본 로고다. 헤어·안경·의상은 고정하고 장면의 내용과 포즈는 목적에 맞게 바꾼다. 같은 장면을 복사하는 것과 공통 인상을 유지하는 것을 구분한다.

## motion.md를 설명하는 말

무엇이 어느 방향에서 얼마나 오래 움직이는지, 여러 요소의 시작 간격, 읽는 시간, 장면 전환을 나누어 기록한다. 교육용 예시는 등장 0.45초, 아래쪽 16px에서 위로 이동, 다음 요소는 0.12초 뒤 시작, 퇴장 0.25초, 전환 0.3초다. 마지막 문구는 1.2초 이상 유지하는 출발 기준이다. 수치는 이번 예시이며 보편적인 정답으로 설명하지 않는다.

## 함께 확인하고 다음 작업으로 넘기기

storyline.md는 장면표·내용과, design.md는 스틸컷과, motion.md는 짧은 재생 구간과 대조한다. 스틸컷 두 장으로 움직임 전체를 확정하지 않는다. 다음 작업에서는 새 주제의 스토리라인을 만들고 확인한 디자인·모션 문서와 실제 자산·스틸컷·기준 영상을 함께 제공한다. 일반 Markdown 파일을 도구에 명시적으로 제공하는 작업 방식이며 전용 자동 설정 파일이라고 가르치지 않는다.

## 예시 파일

저장소 output/webinar-style-docs-examples/의 design.md·motion.md·storyline.md·README.md와 ZIP을 제공한다. 이 design.md는 영상 기준 예시이며 단원 루트 design.md는 계속 PPT 하네스의 장표 디자인 기준이다. 실제 사용자 승인·영상 완료 기록으로 표시하지 않는다.

기존 디자인·브랜드·대표 스틸컷·캐릭터 배치와 움직임을 유지한다. 앱 설치·버튼별 조작·긴 프롬프트·외부 생성 실행을 추가하지 않는다. G10 상속 상태와 lesson.md 원문은 보존한다.
