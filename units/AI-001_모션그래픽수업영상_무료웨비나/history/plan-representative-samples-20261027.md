# 모션 그래픽을 이용한 수업 영상 제작하기 - 대표 5장

작성: 2026-10-27. 사용자가 첨부 이미지로 무료 웨비나 PPT의 대표 약 5장 제작을 직접 요청했다. 이번 산출물은 표지를 포함한 5장 검토용 PPTX와 같은 내용의 PDF다. 전체 강의 제작·최종 승인·7유형 대표 시안 완료로 확대해석하지 않는다.

## 최신 수정 범위 — 원본 에셋과 구조 유지

### 첫 장표 후속 수정 — 주황색과 새 캐릭터 장면

사용자 요청에 따라 첫 장표의 붉은 그라데이션만 주황→검정 그라데이션으로 바꾼다. 제목·보조 문구·일정·브랜드·푸터 좌표와 2~5장 구성은 유지한다. 제공 포스터를 그대로 배치하지 않고, 긴 갈색 머리 여성 교사·안경 쓴 노란 곰·안경 쓴 검정 머리 남성 교사의 외형과 의상 색을 참고해 새 영상 제작 협업 장면을 생성했다. 기존 두 보조 로봇은 새 장면에 넣지 않았다.

원본 생성물 `assets/cover-characters-orange-v3.png`는 투명 알파를 유지한다. 실제 사용한 built-in image_gen 프롬프트는 같은 이름의 `.prompt.txt`, 출처와 파일 해시는 `.manifest.json`에 기록한다. 첫 장표 그림 슬롯 안에 전체 비율을 유지해 배치하고 기존 원본 이미지와 이전 수정본은 보존한다. 이번 요청은 표지 수정이며 전체 강의 디자인 승인으로 간주하지 않는다.

사용자가 기존 시안이 레퍼런스와 다르다고 지적했다. 아래 v1의 청색·새 배치 제안은 이 수정본의 디자인 기준으로 사용하지 않는다. 원본에서 글자·교체 그림·기존 로고를 제거한 실제 배경을 재사용한다. 새 텍스트는 실측 슬롯에 배치하고 사용자 제공 포스터의 인물 영역을 그림 슬롯에 넣는다. 노션톡 원본 로고를 강의별 배경에 합성하며 브랜드 중립 라이브러리는 보존한다. 문구는 편집 가능하고 배경·도형·로고는 고정 에셋이다. 원본 글꼴 패밀리를 알 수 없어 Pretendard를 대체 사용한다.

## 입력과 범위

- 주제: 모션 그래픽을 이용한 수업 영상 제작하기
- 청중: 수업 영상을 직접 만들어 보려는 교사
- 브랜드: 첨부 이미지에 표시된 NotionTalk. 해당 이미지와 직전 브랜드 규칙을 이번 요청의 브랜드 근거로 사용한다.
- 일정: 이미지에 명시된 2026년 11월 1일(일) 20:00. 종료 시각·전체 강의 시간은 미정이다.
- 시각 방향: 첨부 이미지의 차분한 청색과 인물 장면, 기존 연수 레퍼런스의 검정 본문·큰 흰 글자·Part/소주제 위계.
- 푸터: `© 2026. NotionTalk. All rights reserved.`. 모든 장표 우측 상단에 등록된 흰색 NotionTalk 원본 로고를 넣는다.
- 범위: 표지, 모션 개념, 제작 흐름, 장면 구성, 복사 가능한 프롬프트를 대표 장표로 제안한다. 특정 도구 설치나 제품 기능을 다루지 않는다.
- 20초 영상과 3장면 구성은 이번 시안용 실습 제안이다. 확정된 웨비나 교육과정이나 실제 제작된 영상의 성과로 표현하지 않는다.

## 근거와 보호

- P01: 사용자 제공 `codex-clipboard-24232e50-681c-4306-9379-1d4bcf10ef14.png`. 제목·브랜드·일정·분위기·인물 장면의 근거. 원본 전체를 보존하고 PowerPoint 이미지 크롭으로 표시 영역만 조정한다.
- B01: `assets/branding/notiontalk-white.png`. 사용자가 제공한 흰색 브랜드 원본. 이미지 변형·재생성 없음.
- R02: `[사이클 라이브] 클로드 코드로 만드는 일관된 모션 시스템.pdf` PDF 20~28쪽의 정적 장면과 시간·순서 구분, 91~99쪽의 작업 요청서·장면표·시안 확인 흐름을 교육용으로 요약·응용한다. 특정 제품의 현재 사용법은 가져오지 않는다.
- 새로 제안한 교육 내용·장면 구성·프롬프트는 각 장 발표자 노트에 제안임을 기록한다. 원본에 없던 강사명·참가 링크·도구·종료 시간은 만들지 않는다.

## 제작·검토 상태

사용자가 요청한 5장 예시 제작 범위에서 검토용 파일을 만든다. 별도 전체 강의 계획 승인이나 7유형 디자인 확인을 받은 것으로 기록하지 않는다. G03/G09와 전체 제작 체크포인트의 통과 증빙을 생성하지 않는다. 이번 예시는 기존 자동 파이프라인의 전체 통과를 주장하지 않는 수동 대표 시안이다.

원본 보호 G07, PPTX의 구조·장수·글꼴·기하 검증, 모든 페이지의 실제 렌더 검토를 수행하고 기록한다. PDF는 같은 슬라이드 소스로 내보낸다. 실제 모션 재생·실습 도구 리허설·Figma 업로드는 이번 범위에 없다.
