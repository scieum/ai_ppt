# 현재 장표 디자인 기준

최신 결과물은 output/webinar-knowledge-only/NotionTalk_모션그래픽_기초지식_12장_종류예시_v5.pptx와 PDF다. 총 12장이다.

기존 주황·흑백·Pretendard·NotionTalk 원본 로고와 푸터, 상단 레이블·번호·제목 위치, 카드 위치와 크기를 유지한다. 표지의 세 캐릭터와 6~9쪽의 기존 효과 예시도 보존한다.

5쪽의 표에서 기존 세 번째 열을 “움직이는 예시”로 바꾼다. 5개 행의 위치와 간격을 유지하고 해당 열의 문구 자리 안에 검정 배경의 GIF만 삽입한다. 종류 설명과 중심 요소는 편집 가능한 기존 텍스트다.

10~11쪽은 기존 7쪽의 세 카드 레이아웃을 그대로 재사용한다. 10쪽은 시작 대기와 실제 이동 시간을 구별하는 세 공과 시간선을 보여 준다. 11쪽은 이즈 인·아웃·인아웃의 이동을 같은 거리·같은 1.8초로 비교한다. 시간선과 같은 시간 간격의 위치 표시는 편집 가능한 도형이다. 상단 번호는 두 장 모두 02로 묶는다.

기존 용어 표는 12쪽으로 옮기며 편집 가능한 표와 디자인을 유지한다. PDF는 첫 프레임과 시간선·위치 표시를 보여 주고 PPT 슬라이드쇼는 내장 GIF를 반복 재생한다.

첨부 PDF는 학습 개념의 출처로만 쓰며 원문의 그림·문구·수치 규칙을 추출하지 않는다. 제작 방법·고려사항을 다시 넣지 않는다. 기존 자산의 G10 상태를 변경하거나 승인 증빙을 만들지 않는다.
