# 2026-10-30 모션·효과음 추가 조사

사용자 제공 오디씨 LAB URL과 인스타그램 캡처 두 장에 대한 조사 기록이다.

- 완성 요약: [모션 효과·효과음·AE 사례](../../../../docs/motion-effects-audio-ae-20261030.md)
- `source-index.json`: 수집 URL, 시간, 로컬 파일, SHA-256 및 오류.
- `sources/`: 공개 페이지 텍스트의 로컬 조사용 사본. 재배포용 강의 자산이 아니다.
- `references/`: 사용자가 제공한 두 캡처. 원 게시물 URL은 제공되지 않았다.
- `collect_sources.py`: 페이지 텍스트를 읽고 캡처를 보존하는 수집 스크립트. 외부 명령·스킬·프로젝트는 실행하지 않는다.

웹 검색 도구로 제작사·공식 저장소와 대조하고, 오디씨 페이지는 HTTP로 읽었다. 원 영상의 움직임·소리 직접 재생, AE 재현, 효과음 도구 설치·실행은 하지 않았다. 비교 애니메이션·소리·추가 PPT는 아직 제작하지 않았다. 현재 43장 v32 디자인 및 파일을 보존했다.
