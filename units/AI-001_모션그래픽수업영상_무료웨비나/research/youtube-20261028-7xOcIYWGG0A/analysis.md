# 추가 영상 분석과 반영 범위

출처: [이제 모션그래픽은 클로드한테 맡기세요.](https://www.youtube.com/watch?v=7xOcIYWGG0A), 헤이디_일잘러의 업무스킬, 17분 22초.

## 확인한 근거

yt-dlp로 메타데이터를 추출하고 전체 한국어 자막 418구간을 확보해 읽었다. 마지막 자막 종료는 17:14.839다. 제목·설명란의 장 구분과 대조했다. 원본 시각 프레임이나 음원을 분석했다고 주장하지 않는다. 자동 자막에는 도구명·용어 인식 오류가 있을 수 있다. 원본 파일은 로컬 조사 자료로 보존하고 강의에는 자체 요약과 원본 링크를 사용한다.

기존에 GPG 서명과 SHA256·SHA512 검증을 마친 yt-dlp 2026.10.26을 사용했으며 이번 실행 전 실행 파일 SHA256을 당시 검증 기록과 다시 대조했다. 새로 GPG 검증을 수행한 것으로 기록하지 않는다. TLS 검증 해제나 로그인 쿠키 사용은 하지 않았다.

## 내용 구분

- 00:43~04:42: 정지 행사 이미지와 영상 참고 자료를 각각 사용한 제작자의 시행착오다. 현재 강의에서 다시 제작 지시나 결과 품질 보장으로 설명하지 않는다.
- 04:46~06:38: 정지 이미지의 모습과 영상의 움직임을 구분해 요청하는 설명이다. 개념상 연결만 참고하고 프롬프트·요구사항 체크리스트는 가져오지 않는다.
- 06:47~10:40: 브라우저·프로젝트 환경·장면 설명·대표 이미지 확인 절차는 현재 범위에서 제외한다.
- 11:18~11:59: 유리 재질 느낌, 글자 간격·서체 강조에 관한 피드백이다. 이를 새로운 필수 제작 기준으로 넣지 않는다.
- 13:01~13:22: 도형이 달라지고 입체적으로 표현되는 모습, 빛과 그라데이션, 유연하게 흐르는 형태가 언급된다. 이번에 채택한 기초 표현의 출발점이다.
- 13:25~17:11: 번호를 붙인 요청, 대표 이미지 수정, 배경음악, 생성 피드백 등은 제외한다.

## 실제 장표 반영

기존 12장을 유지하고 효과 묶음 끝인 9쪽에 한 장을 추가했다. 세 카드에는 모핑, 입체 회전, 그라데이션 흐름을 배치한다. 이는 언급된 시각 개념을 초보자 용어로 확장한 자체 설명이며 원본이 세 효과를 이 명칭·구조로 가르쳤다는 뜻이 아니다.

새 도형·입체 투영·색 흐름과 GIF는 drafts/video7-concepts-20261028/build/의 코드로 직접 작성했다. 원본의 행사명·포스터·카피·타이포그래피·이미지·음원·프롬프트·장면 구성은 사용하지 않는다. 원본 영상을 장표에 삽입하지 않는다. 실제 앱 실행이나 유료 도구의 현재 기능을 검증한 결과로 제시하지 않는다. 기존 자산의 G10 상태는 그대로다.
