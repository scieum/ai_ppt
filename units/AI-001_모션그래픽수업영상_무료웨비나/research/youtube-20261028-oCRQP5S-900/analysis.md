# 추가 영상 분석 — 톤과 움직임

출처: Ai-Con Lab, [클로드로 만든 모션그래픽 20가지 톤, 전부 코드로 그렸습니다](https://www.youtube.com/watch?v=oCRQP5S-900). 길이 9분 21초. 한국어 자막 199구간 전체와 영상 설명란·챕터를 확인했다. 영상 픽셀이나 원본 음악을 내려받아 쓰지 않았다. 화면에만 있는 세부 구현이나 프롬프트를 확인했다고 주장하지 않는다. 제목의 '전부 코드'는 제작자의 설명이며 이번 웨비나에서 검증한 제작 성과로 표시하지 않는다.

## 네 장의 자체 재구성

7쪽은 동일한 원과 좌우 이동을 손그림·청사진·네온으로 비교한다. '종류는 표현의 중심, 톤은 질감과 분위기'라는 구분은 기존 강의에 연결하기 위한 자체 정리다. 원본의 세계 여행이나 캐릭터를 재현하지 않는다.

8쪽은 크롬·유리, 픽셀, 클레이를 반사·격자·탄성으로 묶는다. 실제 Three.js나 앱 실행 결과가 아니라 이해를 돕는 자체 그래픽 모형이다. 픽셀은 의도적으로 위치 변화가 끊긴다.

13쪽은 형태 전환·시차 이동·카메라 이동을 장면 연결의 세 모습으로 비교한다. 앞서 배운 모핑 정의를 다시 길게 설명하지 않고 화면이 이어지는 역할에 초점을 둔다. 모든 장면 전환이 반드시 연속 변형이어야 한다는 규칙으로 설명하지 않는다.

14쪽은 같은 네 박자에 크기·선·단어 강조가 반응한다. 점등 표시가 박자를 나타내는 무음 예시다. 실제 소리 분석이나 실시간 음악 반응 시스템이 아니며 원본 음원을 넣지 않았다.

## 저작권 검토 기록

원본 제목과 URL은 출처 안내에만 사용한다. 장표 문구는 새로 작성했고 꽃·신문·캐릭터의 세계 여행·원본 화면·음원·앱 화면·프롬프트를 삽입하지 않는다. 12개 GIF는 새 프로그램 도식이며 코드와 파일 해시는 자체 에셋 manifest.json에 기록한다. 사용자 소유 노션톡 자산과 기존 디자인을 유지한다. 이 신규 자산 기록은 기존 상속 자산의 G10 미확인 상태를 통과시키는 근거로 사용하지 않는다.
