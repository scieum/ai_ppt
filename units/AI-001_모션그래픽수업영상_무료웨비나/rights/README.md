# 현재 권리 검토 상태

2026-10-27 · 미확인. 이 폴더는 실제 검토·승인을 완료했다는 기록이 아니다.

원본 PDF에서 추출한 배경·도형·도구 로고와 이를 이용한 기존 대표 PPTX/PDF는 이용 근거와 배포 범위를 확인하지 못했다. 파일은 이력으로 보존하고 G10 검토를 통과한 배포본으로 사용하지 않는다. 사용자 제공 노션톡 로고는 사용자의 자산이라는 명시적 설명과 이번 작업의 사용 요청이 있다. 다른 참조·캐릭터·도구 표식까지 같은 허락을 확대하지 않는다.

`open-issues.json`에 확인할 항목을 남겼다. 실제 등록 출처·사용 자산·배포 계약이 준비되면 [G10 계약](../../../docs/copyright-review.md)에 따라 `inventory.json`, `scan.json`, 사람의 `review.json`을 작성한다. 미확인 항목을 임의로 닫거나 모의 승인으로 대체하지 않는다. 현재는 G10 통과를 기대하지 않는다.

Part 1의 새 교육 구성은 [part-1.md](../part-1.md)에 제안했다. 계획 작업은 계속할 수 있으며 제작 시 해당 문서와 실제 사용하는 자산도 검토 범위에 등록한다.
